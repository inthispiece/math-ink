# MathInk 整页数学笔记：配置和试用

2026-10-27 开发预览采用“笔记库 → 多页书写 → 按需工具箱”。单页识别自动进入本篇草稿箱，整文档识别先保留任务结果，再由用户选择草稿或独立笔记。打开即可写笔记，模型配置只在需要识别时进行。当前真实 DeepSeek 云端质量与费用评测仍未执行；工程流程可测试不等于内容保留率、纠错率或节时目标已通过。原生安卓/鸿蒙安装包、商城发布及真机笔感验收继续单独推进。

本轮更新候选为 `0.1.0-preview.9`，对应 [BUGFIX-002 v1.0](bugfix-plans/BUGFIX-002.md)，状态“待验收”；实际提交及最终测试结果见 [开发预览记录](DEVELOPMENT-PREVIEW.md)。上一批 BUGFIX-001 的真机验收继续保留。

在笔记库“设置”，或笔记“更多 → 应用设置”中展开“识别服务与账号”，选择 DeepSeek、本地 Qwen（Ollama）或 Mathpix。保存后影响新任务，无需重启网关；已有任务仍使用原服务和账号查询。修改电脑 `.env` 中凭据、模型或地址后需要重启。“新笔记手写引擎”仅影响以后新建笔记，不转换已有原稿。

## 两个独立操作

- **识别公式**：复用工具栏普通“套索”的有效选区；未选时提示先圈选。圈选、移动和缩放本身不上传；只有纯笔迹选区在核对图片和范围后才能明确提交。混选笔迹/公式或只选排版公式会提示调整，不能预览整个范围却只上传一部分。转写忠实保留积分限、不等号、范数、上下标、矩阵和多行，不求值或补条件。成功自动保存为本篇草稿，仍需人工核对。
- **检查公式**：工具箱“更多数学工具”，或草稿详情中独立调用。只发送所填 LaTeX 和补充条件，不附带图片或整页笔记。原式、问题和建议独立展示，用户明确采用才修改检查草稿；不会自动替换正式内容。无需识别时可先从“手工创建草稿 → 输入 LaTeX 公式”开始。

AI 提出的数学修改需要人工核对，不能用一条模型建议作为定理证明。原稿和已整理公式不会被后台替换。

## 常规套索与撤销

工具栏“套索”可选择笔迹和已插入公式，拖动选区移动，用控制点等比缩放；“平移”和双指缩放只导航页面。点击空白或 Escape 清除选择；变换进行中先取消本次手势、恢复初始内容。切换笔/橡皮/平移会清理选择。识别预览关闭后仍留套索可保留选区，明确返回书写或提交后才清理对应选择；迟到结果不清掉新的选区。

实验画布当前会话内按笔记和页面分别撤销，笔迹、插入、删除、编辑和一次移动/缩放手势按操作顺序处理。撤销删除恢复同一实例，草稿不回滚。Butterfly 使用当前笔记文档的原生时间线，可能涉及别页，会提示受影响页；不会连续跳过别页事件。历史已执行但保存失败时，点击“重试保存”仅保存当前状态，不再次执行撤销/重做；完整历史跨应用重启恢复不是本轮承诺。

## 文件夹、PDF 与干净阅读

笔记库的“全部笔记”保留总览，“未分类”和单层文件夹用于筛选。可新建、重命名文件夹；笔记菜单选择“移动到文件夹”，或将卡片拖到目录。触摸需长按后拖动，普通滚动不移动笔记；无效目标或取消保持原归属。移动后可短暂撤回，后续又移动过的笔记不会被旧撤回覆盖。删除文件夹只把笔记移回未分类，包含回收站里的笔记，不删除正文。文件夹内新建默认归入当前目录。

笔记库选择 **导入 PDF**，或在笔记“更多 → 导入 PDF”选择文件。预览原页数、缩略图和导入范围（如 `1-3,5`），确认新建笔记的名称/文件夹，或追加到原笔记当前页之后。当前面板会列明大小与页数限制，超限先拆分文件。需要密码的 PDF 本版拒绝导入；不会以空白页冒充成功。导入只保存原文件和页清单，不调用 AI。

PDF 原文是固定底图，笔迹和公式是独立批注层。套索、橡皮只操作添加的内容；要将原文转为可编辑段落和公式，需另行识别。原尺寸、旋转、页序与批注位置跟随页面保存，完整备份包含原 PDF；PDF 本身不代替可恢复编辑状态的 MathInk 备份。

笔记菜单或“更多 → 导出 PDF”会先冻结文档。选择正式页范围、质量和是否排除确认空白页，点击 **生成输出预览**，检查实际输出页数及原页归属后下载。空白页默认保留，已删除页、未插入草稿、任务与编辑按钮不导出。原 PDF 页保留内容并叠加批注；普通手写/排版页标为图片模式，不承诺全部文字可搜索或复制。纸面外的手写内容显示完整范围并缩放适配；长排版页按段落和公式续页，不把整篇压成一张小图。导出分页不修改笔记。

由识别草稿加入或整文档另存产生的正式排版页，默认是干净阅读。工具栏 **撤销 → 重做 → 编辑模式** 中打开编辑模式后，选中块再编辑、增删、移动或查看原稿；关闭后隐藏操作控件并保留阅读位置。开关本身不改正文或生成内容历史，实际编辑可撤销/重做。切页或重开回到阅读状态。旧“原有整理内容”页继续提供原编辑入口；保存失败时先重试或导出，不通过关闭编辑丢弃现场。

## 识别整个文档

1. 在笔记库卡片菜单，或笔记内部“更多”选择 **识别整个文档**。两处打开同一个任务区，可重开已有结果；“准备新的整文档识别”只保存并冻结当前可见正式页清单，不提交模型。
2. 核对原页序、总页数、需要模型的页及原服务身份。手写/PDF 页发送完整冻结图片；已有排版页直接复制正式结构，已确认空白页保留位置，不生成模型费用。回收页、草稿及其他隐藏任务不在发送范围。后续修改原稿不混入本批；后台取图不切走前台页。
3. 勾选本批发送同意，再点 **确认并提交整文档识别**。当前整页结构化主线为 DeepSeek；Qwen 尚未开放整页能力，不自动切云。按页串行处理，进度区分生成、原始响应保存和解析保存。页数是调用需求，不等于实际 token 账单；额度或金额限制到达后暂停后续页。
4. 关闭结果面板、切页或继续书写不会自动新建正式笔记，也不把每页塞成很多草稿。任务区保留按页结果、错误、原始响应和归档回执。刷新后先 **查询原请求**，不重做成功页；恢复完整备份不会自动生成，未提交页必须再次明确继续。
5. 选择 **加入草稿箱**，形成一条可按页核对编辑的整文档草稿，之后明确加入全部或指定排版页；或填写名称和文件夹，选择 **另存为新的笔记**。这两步复用已保存结果，不再识别。新副本页、块、公式及实例独立，保留本地历史原图和原笔记来源身份；后改草稿、补齐失败页或删除原笔记，不自动改写已归档副本。

部分失败显示“部分完成”。明确勾选保存部分结果后，失败页在原位置保留原图和说明，可手工补录；不会静默缺页。暂停只停后续提交，取消剩余页不能撤回已经开始的供应商计算。未知状态先查询，明确重试失败页才建立新请求，默认沿用本批原快照；使用后来修改的原稿需要准备新批次。

如果结果已收到但本地写入失败，先 **导出任务与收到结果**，再 **重试本地保存**；不要以再次识别代替保存。任务区的“恢复收到的整文档结果”按原任务恢复该文件，不等于普通笔记备份。服务缓存或本机材料缺失时不能保证找回正文。重复归档同一结果版本只生成对应的一份产物；要另一份独立笔记，使用 **明确另存一个副本**。

## 翻页与缩放

阅读/平移状态下，纸面适配宽度时可单指横滑翻页；放大溢出时先平移，到边界抬手后再向外滑才翻页。纵向继续阅读或平移，一次手势最多翻一页。笔输入、手指书写、套索变换或公式放置期间，纸面继续操作内容；下方导航区域可作为等价翻页入口，但须先结束笔画/变换或明确取消放置。双指全程只缩放和平移，不在松手时翻页；保存失败留在原页。

页面下方短暂显示真实缩放百分比，点击读数恢复 **100%（逻辑 zoom=1）**；空白非交互区域的触摸或桌面双击有同等复位。手指书写开启时用百分比按钮，避免把笔画当双击。**适合纸面** 是另一个按可用宽度计算的操作。视图按页保存，不改变公式实例大小或进入内容撤销；横竖屏、笔压、掌触和连续手势仍需目标安卓/鸿蒙真机验收。

## A. 配置 DeepSeek 云端

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com)注册登录，创建 API key。免费聊天账户不代表 API 免费；余额和调用费用在开放平台管理。模型与价格以[官方页面](https://api-docs.deepseek.com/quick_start/pricing/)为准。
2. 本地编辑 `D:\note\.env`。其他电脑首次复制 `.env.example`，不要覆盖已有凭据。填写：

```dotenv
OCR_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_TIMEOUT_MS=45000
```

当前官方 `deepseek-flash` 支持图像输入，转写时关闭长推理并要求结构化结果；不要换成仅支持文字的模型。[官方视觉接口](https://api-docs.deepseek.com/guides/vision/)

3. 关闭旧 MathInk 服务，运行 `Start-MathInk-Lan.cmd`。电脑强制刷新页面，平板打开启动窗口显示的配对链接。
4. 打开“应用设置 → 识别服务与账号”，选择 **DeepSeek 云端**并保存。检查服务连接会验证服务配对和模型就绪，不上传公式、不生成内容。密钥只存在电脑服务端；浏览器“服务配对令牌”不是供应商 API key。
5. 新建或打开笔记，普通套索选中纯笔迹后点击识别，或从工具箱选择“识别公式”并按提示选择。核对本次原图及范围再明确提交。检查公式另有文本发送范围；每次操作都需确认，不沿用不适用的供应商或范围授权。

没有配置可用 key、余额不足、模型错误或网络失败时会明确提示，不会返回演示公式，也不会自动切换供应商。云端成功的连通检查不保证下一次生成必定成功。

## B. 配置本地 Qwen3-VL-2B

这里的“本地”指电脑运行模型，安卓/鸿蒙平板通过同 Wi-Fi 的 MathInk 网关调用。电脑需保持运行；平板无需安装模型或访问 Ollama 端口。

这台电脑已准备项目内的 Ollama 便携运行时和 `qwen3-vl:2b-instruct` 权重。其他电脑先安装 [Ollama for Windows](https://ollama.com/download/windows)，然后执行下面的模型下载步骤。模型约 1.9GB，实际运行内存还包含视觉编码和上下文开销。[官方模型](https://ollama.com/library/qwen3-vl:2b-instruct)

固定使用显式 `2b-instruct` 标签。Ollama 当前的 `qwen3-vl:2b` 别名会选到 Thinking 权重，实测可能耗尽输出预算而没有转写；不能只靠 `think:false` 将其变成 Instruct。

`.env` 中保留：

```dotenv
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3-vl:2b-instruct
OLLAMA_TIMEOUT_MS=180000
```

首次下载或恢复下载：

```powershell
.\Setup-Qwen.cmd
```

也可使用已安装的 Ollama CLI：`ollama pull qwen3-vl:2b-instruct`。项目启动助手在自己启动的服务中使用 `.local/ollama-models` 保存权重；若复用已运行的 Ollama，其模型目录由那个服务决定。

每次试用时先运行并保持窗口打开：

```powershell
.\Start-Qwen.cmd
```

然后运行 `Start-MathInk-Lan.cmd`，在设置中选择 **本地 Qwen**、保存，再检查连接。未启动服务、未下载模型、不是视觉模型都会有明确提示。本地助手和网关只连接回环地址，不需要把 Ollama 对局域网或公网开放；平板填写的是电脑的 MathInk 地址，不是 `localhost:11434`。

本地模式不调用 DeepSeek，不需要云端 key，也不扣云端次数。每次生成前会检查模型能力及远程别名，拒绝 Ollama 云模型；不会在本地失败后偷偷切云端。首轮加载可能较慢，界面有取消，默认最长等待约 185 秒。当前使用 4,096 上下文和有限输出，本地检查的公式加条件太长时会提示分段，避免无声截断。

`pnpm local:status` 可只检查本地模型是否下载及可用，不生成内容；`pnpm local:pull`、`pnpm local:serve` 与两个 CMD 入口对应。

整页转写、上下文检查、整理、AI 关联和证明步骤任务目前只开放 DeepSeek。选择 Qwen 时会明确禁用这些任务，保留手工编辑、已有选区公式实验、搜索和人工链接。失败不会自动转云端。托管 HTTPS 服务的用户电脑和服务器不是同一台机器，不能将服务器的 `127.0.0.1:11434` 当成自己的 Ollama。托管页先使用启动说明进入自己电脑/局域网入口，必要时通过完整备份搬移笔记；不承诺从托管页面一键连接本机 HTTP 模型。

## 普通书写与整页草稿

1. 启动先进入“我的笔记”。新建后立即可写，页面概览管理新增、插入、复制、排序、删除和恢复；每页保留纸张、笔迹及缩放位置。返回首页再打开恢复上次页。普通书写不要求 AI 配置。
2. 需要整理时在当前页打开 **工具箱 → 识别整页**。查看页码和完整页预览后明确提交；实验画布与 Butterfly 均按当前完整页渲染，包含视口外内容，不沿用圈选授权。首版优先较清晰的单栏中英数学笔记。
3. 提交前保存任务占位，成功自动变为原笔记草稿箱的一条整页草稿。识别期间可继续写字、换页或换笔记，结果不抢焦点、不自动增加页面或笔记。未支持的图形区域保留原图，疑点和未知内容保持待核对。
4. 打开草稿详情，对照原稿编辑、拆分、合并、重排段落和公式；修改自动保存，关闭详情不丢已保存结果。核对标记不等于数学证明通过；来源变化或删除时仍可查看历史快照，明确使用历史版本才能插入。
5. 草稿独立长期保存。公式选择“插入当前页”后点击放置位置；整页选择“作为排版页加入笔记”后新增排版页，保留手写原页，新排版页默认干净阅读。用重做右侧的“编辑模式”修改正式内容。每次插入为独立副本，改草稿不改旧实例，撤销插入不删除草稿。草稿回收也不会删除已插入内容。

断网时已打开笔记仍可书写和保存；生产预览先成功加载并缓存静态资源，才可离线重开，开发服务器热更新页面不作为离线发行保证。云端识别依赖联网，本地 Qwen 依赖电脑模型服务可达。

选区识别及整页任务刷新后只 **查询原任务（不重新生成）**；如果服务重启或缓存过期，正文可能不可用，本机已有草稿仍保留。原连接或账号失效时显示等待恢复，不改发新后端。同步文字公式检查中断后不保证能查询原结果。只有明确 **重做（可能再次计费）** 才创建新调用；取消不能保证供应商撤回已发生计算，未知用量继续占用保守预留。

## 结果已收到但未保存，如何恢复

模型返回与设备保存是两件事。列表/详情会显示“结果已收到”“正在本地保存”“已收到，待保存”或“结果已保存”。“已收到，待保存”时可查看未保存预览、复制或 **导出收到的结果**；先保留文件，再点 **重试保存收到的结果**。它只重放本地保存，不新增识别请求。存储确实不可用时，不能保证状态本身也可落库，未导出前不要清理浏览器或关闭页面。

旧版导出的未保存文件是原始 Reply，不是完整笔记备份。更新后从 **草稿箱底部 → 恢复收到的结果** 选择该 JSON，应用按本机原任务 ID、供应商、来源版本及结构校验后恢复，不按当前打开的笔记猜归属。没有匹配原任务会拒绝；已刷新又没有导出文件时先查询原任务，缓存已消失则不能保证恢复正文，是否重新生成由你决定。

## 上下文纠错、整理与来源关联

在笔记工具箱“更多数学工具”，或草稿详情打开相应工具，勾选当前内容块并查看发送范围。上下文检查和整理每次单独确认，只发送展示范围的文字及公式，不自动附带原稿图片或其他笔记。

- **修改建议**按识别疑点、语言表达、数学问题、缺少条件区分，显示改前、改后、理由和引用依据；原稿可能写错与识别可能看错分别处理。逐条接受、拒绝或勾选批量接受；只有版本仍有效且不互相冲突的目标会修改。
- **撤销采用**恢复原内容；如果采用后用户又编辑目标，安全撤销会拒绝覆盖新内容。任何相关正文、公式、上下文或原稿变化都会使旧建议只可查看，需要重新检查。
- **整理草稿**保留所选原条件、公式和来源，并把摘要及新增解释标明为 AI 内容。结果留在本篇草稿箱，不自动新建笔记；用户另行决定是否加入排版页。
- **本地检索**覆盖正文、公式和标签，支持人工链接、反向链接和准确块跳转。删除或编辑目标会显示断链或需要核对。AI 关联只查看主动勾选的笔记范围及有限相关块，显示引用和理由，明确采用后才建立关系；没有依据可以不生成。
- **证明步骤建议**仅面向初等代数和基础微积分，展示目标、假设、已有步骤、下一步和未解决问题，始终标为“未验证”。逐步采用为草稿，不表示已经证明；未接入 Lean 等形式验证。

工作台的 **本地多项式核对** 是与 AI 分开的确定性工具：仅处理有理系数单变量多项式恒等式，或候选原函数的导数是否等于给定多项式。使用 ASCII 输入，如 `x^2`、`x^3/3+C`。工具会给出支持范围、精确结果或反例；不传云端，不修改笔记，不把数值样例或有限范围核对标成一般证明。

## 备份升级与换地址迁移

当前完整备份为 **schemaVersion:4**，包含稳定笔记/页/公式/来源 ID、每页原稿和视图、草稿箱、单页与整文档任务、建议、历史快照及使用记录，并保留文件夹和 PDF 二进制资源。同一原 PDF 按唯一资源编码一次；“所有笔记”备份包含空文件夹，单篇备份携带所需目录、原文件与历史来源。兼容导入 schema 1/2/3：旧笔迹迁入手写页，旧正式正文作为“原有整理内容”排版页继续可见和编辑，不经 AI 重写；没有目录的旧笔记归入未分类。旧客户端会拒绝新格式。

完整备份下载可使用 schema 4 的可选资源池：规范 PNG/JPEG 图片、整页输入中等价的图片字段、重复的 Butterfly 原始归档按内容哈希只编码一次。导入先校验资源与引用，再还原原始字段和独立归档数组，不重打包原稿，不改变来源身份。没有资源池的旧 schema 4 仍可读；不可识别或非规范的旧图片原文保留。超过文件、资源或展开保护上限会明确拒绝，现有笔记不改，应按笔记拆分并保留原文件。原始 Reply 和整文档任务恢复 JSON 继续使用各自协议，不当作完整备份导入。

Markdown、LaTeX 和思源常规导出只包含正式页面，未插入草稿、任务及私有快照不会混入；**完整 JSON 备份才保留整个草稿箱**。草稿详情也可单独导出。升级、换地址或分享前请区分正式内容导出和完整备份。

同一浏览器来源首次升级 IndexedDB 至 4 时，在同一事务先保留旧格式恢复快照再迁移；迁移失败会回滚，原数据库不变。使用“导出升级前恢复备份”可保留恢复材料。格式无效的导入不会改现有存储；目录 ID 或名称冲突时明确选择现有目录、未分类，或新名称与新目录 ID，不因同名自动合并。遇到已有笔记 ID 仍需先导出当前备份、再明确确认覆盖恢复，来源身份保持稳定。恢复后的整文档任务先核对原连接和原请求，未提交页需主动继续。

整理草稿保留原笔记的来源身份。单篇备份恢复后若原笔记不在设备上，仅在实际原稿、页和完整版本严格匹配时定位到保存的副本，并显示说明；副本有变化时需要导入原笔记备份。Butterfly 文档仅重新打包也可能触发保守拒绝，因此跨入口迁移优先使用所有笔记的完整备份。

电脑局域网地址、`localhost` 和托管 HTTPS 域名的浏览器存储彼此隔离，不会自动迁移或同步。换入口请按以下顺序操作：

1. 在旧入口导出 **所有笔记 · 完整 JSON**，保留文件和旧入口数据。
2. 在新入口选择恢复，检查版本、笔记数量及冲突提示。
3. 抽查正文、行内/独立公式、原笔迹、来源跳转和附件，重新导出新入口备份确认可读。
4. 核对完成前保留旧数据。云端推理账号登录不等于笔记同步。

## 托管邀请测试与评测

本机/局域网开发使用配对令牌。托管服务使用独立账号、邀请注册和可撤销会话；用户登录后由服务端账号计算次数及费用，不能通过更换 `installationId` 获得新额度。供应商密钥只保存在运营者服务器，用户无需安装 Ollama 或填写 DeepSeek 密钥。账号、费用保护与部署代码已经提供，但实际 HTTPS 域名、服务器、运营预算及邀请分发需要另行配置，不能仅修改模型设置就获得可用公网服务。

评测工具见 [evaluation/README.md](../evaluation/README.md)。`node scripts/eval-ai.mjs init` 会建立本机私人清单和 40 道待核对候选检查题，预拟正确/错误各半，全部 `humanVerified:false`。尚未收集的真实页面不填作已有样本。真实调用必须显式 `--allow-paid --budget-cny 金额`，默认最多 3 条，提交前持久化请求标识和保守费用预留；未知请求不自动重做。报告保留模型、提示词、延迟、用量、人工核对及费用未知状态，不制造准确率。

## 如何试用并判断是否有效

1. 写一个不定积分 `∫x² dx`。点击转写，核对结果没有擅自添加上下限或计算答案。
2. 再试 Hölder 不等式、矩阵、分段函数和两三行推导。检查不等号、范数下标、矩阵行列及是否漏行。结果不确定时可直接修改 LaTeX。
3. 在 LaTeX 编辑框填 `\int x^2\,dx=\frac{x^3}{2}+C`，手动补充“检查对 x 的不定积分计算”，点击检查。核对模型建议，确认原编辑框没有被自动改动；再决定是否采用。
4. 切换 DeepSeek/本地 Qwen，在相同原稿上比较完整转写正确率、修正耗时、延迟和云端用量。建议先收集 30–50 条真实笔迹，再扩充测试集。

本地 2B 当前标为实验模式。2026-10-23 在本机 RTX 3050 Laptop 4GB 上真实运行：鼠标手写 x² 转写成功约 42.8 秒；用户截图的不定积分上标误读但标记不确定；Hölder 截图达到输出上限并被拒绝接收；错误积分等式两次检查均未发现数学错误。独立检查请求约 2.8–5.2 秒。这里没有声称复杂识别或数学纠错已达到可用准确率，须逐项核对；可切换云端做对照，DeepSeek 仍需配置真实凭据后验证。接口回归使用隔离响应，不能作为真实准确率结论。

## 额度、重试与数据

- DeepSeek 和 Mathpix 的真实云端转写、检查、整页及其他任务共用本服务的次数和金额保护。次数可由本机运营配置调整；托管模式按可信账号计算，设置中的用量及重置时间以运行中的服务为准。
- 默认金额保护为每用户每天 5 元、每月 50 元，全服务每天 50 元、每月 500 元；与次数上限同时生效。没有当前模型价格时，本地每次占用 0.5 元预留，未知费用不自动释放，所以即使次数有剩余也可能停止生成。预留不是实际账单，也不是未知价格下的费用保证。可按 [部署说明](../deploy/README.md) 配置 `AI_PRICE_CONFIG` 的实际模型、日期及价格，使返回有效用量的调用按估算结算；金额配置在 `.env` 中调整后重启。托管模式没有有效价格时不会调用供应商。
- 本地 Qwen 不扣本服务的云端次数，性能仍受电脑资源限制。供应商 token 账单及余额与本地次数分开；运行中的服务预算通过鉴权后的 `/v1/usage` 查询，额度不足在对应工具提示。
- 进行中的双击合并，不会自动重复请求。用户主动点击“重新转写/重新检查（可能再次计费）”会新建一次调用；已送达供应商的失败或超时仍可能收费。取消等待不能保证供应商撤销已发生的计算。
- 切换笔记或收起面板不取消任务；切换后端只影响新任务。修改目标正文、公式或来源后旧建议不能直接覆盖新内容；任务中的手工草稿修改优先保留，模型结果另存。拒绝上传、取消、失败均保留原稿。
- 配对令牌、`.env`、模型文件和个人笔记不提交 GitHub，也不放入预览包。服务端结果正文仅在内存中缓存，SQLite 保存请求/任务、用量、预算和账号必要元数据，不保存笔记、图片、公式或补充条件正文。本机 IndexedDB 则保存原稿、草稿、建议和任务恢复材料。

整文档任务如果显示“原始结果已保存，但解析失败”，先使用结果区的“重试本地解析（免费）”。这只处理本地响应；“重试本地保存”也不重新生成。明确重新识别失败页会使用新请求，仍可能计费。
