# 发布验收

此清单中的未验收项不能因生成了文件而自动勾选。

- [ ] 公开源码、固定提交、补丁、许可及对应构建说明完整
- [ ] 类型检查、网关/状态/几何测试、浏览器流程测试通过
- [ ] Butterfly 修改版真实构建并在两端加载，无远程画布依赖
- [ ] DeepSeek 真实页面/公式检查分组评测、费用和延迟通过；Mathpix 仅可选对照
- [ ] 整页中英混排、阅读顺序、关键条件及整式正确率独立人工验收；不能以接口测试替代
- [ ] schema 1/2→3 可恢复迁移、跨入口完整备份、内容/来源版本、建议过期与撤销通过
- [ ] 托管账号隔离、撤销、可信用户额度、次数/金额/并发/频率保护及未知费用对账通过
- [ ] 任务取消、部分失败、重启结果丢失和明确重新计费流程通过，不自动重发
- [ ] 鸿蒙 5.1+ 真机与手写笔：连续书写、掌触、笔压、套索、缩放、旋转、后台恢复
- [ ] 安卓 10+ 真机与手写笔验证；模拟器功能检查
- [ ] 大笔迹页保存一致、备份恢复、升级保留数据、与原版思源共存
- [ ] 30 个真实公式打通后，完成约 300 个不同书写者样本的分组评测
- [ ] 独立服务域名、HTTPS、费用总额度、运营者联系方式可用
- [ ] 开发者实名认证、应用业务分类、资质、适用 APP 备案完成
- [ ] 自有图标、名称、截图、隐私政策、支持入口与商店声明一致
- [ ] 安卓签名 APK 与鸿蒙签名 APP 对应明确源码提交
- [ ] 华为邀请测试通过，两端提交并取得审核结果

GitHub 预览发行标注预览状态，不能写“已上架”“识别准确率已达标”或“鸿蒙笔感已验证”，除非有实际证据。
