# 开发预览验收记录

## 2026-10-27：笔记优先、多页与持久化草稿箱

本轮构建标识为 `0.1.0-preview.7`。新代码与说明按 [前端交互计划](FRONTEND-INTERACTION-PLAN.md) 改造。类型检查、271 项核心测试、68 项浏览器测试及离线构建通过；另外验证实际 Butterfly 页面、生产手写与恢复、解压预览离线重开和托管账号隔离四项生产流程。隔离响应不代表真实模型准确率。

- 启动先进入“我的笔记”，空库不自动建笔记、不弹出模型配置。新建后直接进入第一张空白纸；普通书写、多页、手工公式、检索及备份不依赖 AI。工具箱、页面列表和本篇草稿箱按需展开。
- 每页有稳定 ID、独立笔迹、纸张和缩放位置，支持新增、插入、复制、排序、删除及恢复。切页先保存，保存失败保留现场并提供重试/导出。笔记可重命名、置顶、复制、回收及恢复；后台结果不改变最近编辑排序。
- 公式圈选不上传，提交前单独预览选区；整页识别预览完整当前一页。成功结果自动存进原笔记草稿箱，不改正式内容、不翻页、不抢焦点、不新建笔记。草稿编辑自动保存，核对、复制/导出、插入、回收是独立操作。
- 公式插入须明确放置位置，整页草稿须主动加入为一张排版页。每个插入实例有独立内容与版本；草稿反复使用、修改和回收不影响已插入实例。来源改变或删除仍保留历史快照，旧建议不能覆盖新内容。
- 应用任务管理按原笔记、来源页、输入版本、服务和身份保存结果。后台草稿提交与最新笔迹在事务中合并；软删除结果仍留在回收状态，永久删除使用 tombstone 阻止晚到结果复活。请求中的手工草稿修改也会保留，模型结果另存。
- 新增异步选区识别 `/v1/recognitions` 与按原请求查询，整页及其他工具沿用 `/v1/tasks`。重新打开仅查询原 ID，不隐式发起新生成。原连接失效显示等待恢复；服务重启或缓存过期可能无法恢复正文。同步文字公式检查中断后不可保证可查询，明确重做才可能再次计费。
- IndexedDB 和完整备份升级为 **3**，同事务保留版本 1/2 的原格式恢复快照。旧笔迹迁入手写页，旧正式正文保为可访问、可编辑的“原有整理内容”页，块/公式/来源 ID 保留；旧 Butterfly 全部页由原生文档枚举，不能只按已访问的宿主页列表迁移。
- Markdown、LaTeX 和思源导出只含正式页面，思源上传资产也排除未插入草稿、任务和私有快照；完整 JSON 备份包含草稿箱、用量和恢复材料。草稿可在详情中单独导出。
- 设置中的手写引擎只决定新笔记默认值，已有笔记固定使用自己的引擎。原生撤销/重做根据实际 `.bfly` 内容同步插入与使用状态，不把已撤销公式继续作为正式内容导出或本地检索。
- 真实 DeepSeek 页面质量与费用评测本轮仍未执行；没有新增准确率、内容保留率或节时成绩。100 篇×30 页自动化仅是桌面实验基线，目标安卓/鸿蒙平板的笔压、掌触、延迟、旋转和后台恢复仍待真机验收，未交付已审核的商城安装包。

试用：运行 `Start-MathInk.cmd`（平板同 Wi-Fi 用 `Start-MathInk-Lan.cmd`）→ 新建笔记 → 书写并新增页 → 返回首页再打开。需要识别时再打开工具箱，凭据仍在电脑/服务器 `.env` 配置，见 [AI-SETUP.md](AI-SETUP.md)。断网时已打开笔记可继续写；离线重开依赖生产资源已成功缓存，不支持首次离线访问或离线云识别。

旧测试的逐项迁移与新覆盖范围见 [FRONTEND-TEST-MAP.md](FRONTEND-TEST-MAP.md)。真实付费评测没有启动，商城发布仍未执行。源码与对应开发包见 [GitHub 预览发行](https://github.com/inthispiece/math-ink/releases/tag/v0.1.0-preview.7)。

桌面 Edge 的固定实验数据为 100 篇笔记、共 3,000 页：写入测试库 57.8 ms，重新进入书库并显示 100 张卡片 497 ms，连续切换 5 页共 350 ms。数据来自自动化测试的一次运行，是实验画布的桌面基线，不是目标平板、原生画布、大笔迹页或笔尖延迟结果；后续必须另测真机笔压、掌触、内存与后台恢复。

## 2026-10-23：DeepSeek 与本地 Qwen，转写与检查分离

- 设置可选 DeepSeek、Ollama 本地 Qwen 与 Mathpix。转写只上传选区 PNG，检查只提交编辑框公式与用户填写条件；云端按操作、供应商明确同意。建议独立展示，采用后进入编辑框，确认整理才保存。
- 默认本地模型固定为 `qwen3-vl:2b-instruct`。实测发现浮动 `qwen3-vl:2b` 标签指向 Thinking 权重，忽略 `think:false` 并耗尽输出预算；没有将思考内容冒充转写。提供 Setup-Qwen.cmd / Start-Qwen.cmd，其他电脑另装 Ollama；模型与运行时不放入源码或 ZIP。
- TypeScript 类型检查、114 项核心测试及离线应用/插件构建通过；最终完整 39 项 Edge 浏览器回归通过。实际 ZIP 解压运行、离线重开及 Butterfly 手写/套索/来源恢复验证通过。适配测试覆盖深度视觉请求、JSON schema、超时/截断/拒绝、模型探测、云别名拒绝、配额与新 ID 明确重试；隔离响应不能证明识别准确率。
- 本机 Ollama 0.40.9、Qwen3-VL-2B-Instruct Q4_K_M，RTX 3050 Laptop 4GB 通过 Vulkan 运行。隔离浏览器真实鼠标 x² 返回 `x^{2}`，约 42.8 秒；独立检查原式未自动覆盖，采用须点击，未自动保存公式，页面异常和外部页面请求均为零。所有推理只走本机，无付费调用。
- 真实质量存在明显限制：用户积分截图上标误读但标了不确定；Hölder 截图输出超过上限被拒绝；错误积分等式两次检查均未发现错误。后者约 2.8–5.2 秒。本地模式标为实验，不能宣称适用于可靠复杂数学识别/校对。用户截图和结果只保存在被忽略的本机实验目录，没有提交或打包。
- DeepSeek 按官方支持图像的 `deepseek-flash` 接口实现；本机没有其凭据，真实云端调用、费用与样本质量尚未验证。配置与试用步骤见 [AI-SETUP.md](AI-SETUP.md)。本次不代表完成 Android/Harmony 原生安装包或商城验收。

## 实验入口

在本机 `D:\note` 运行 `.\Start-MathInk.ps1`，打开默认地址 `http://127.0.0.1:8787`。开发源代码热更新使用 `pnpm dev:demo`，默认地址为 5173。
