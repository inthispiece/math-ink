## 2026-10-23：DeepSeek 与本地 Qwen，转写与检查分离

- 设置可选 DeepSeek、Ollama 本地 Qwen 与 Mathpix。转写只上传选区 PNG，检查只提交编辑框公式与用户填写条件；云端按操作、供应商明确同意。建议独立展示，采用后进入编辑框，确认整理才保存。
- 默认本地模型固定为 `qwen3-vl:2b-instruct`。实测发现浮动 `qwen3-vl:2b` 标签指向 Thinking 权重，忽略 `think:false` 并耗尽输出预算；没有将思考内容冒充转写。提供 Setup-Qwen.cmd / Start-Qwen.cmd，其他电脑另装 Ollama；模型与运行时不放入源码或 ZIP。
- TypeScript 类型检查、114 项核心测试及离线应用/插件构建通过；最终完整 39 项 Edge 浏览器回归通过。实际 ZIP 解压运行、离线重开及 Butterfly 手写/套索/来源恢复验证通过。适配测试覆盖深度视觉请求、JSON schema、超时/截断/拒绝、模型探测、云别名拒绝、配额与新 ID 明确重试；隔离响应不能证明识别准确率。
- 本机 Ollama 0.40.9、Qwen3-VL-2B-Instruct Q4_K_M，RTX 3050 Laptop 4GB 通过 Vulkan 运行。隔离浏览器真实鼠标 x² 返回 `x^{2}`，约 42.8 秒；独立检查原式未自动覆盖，采用须点击，未自动保存公式，页面异常和外部页面请求均为零。所有推理只走本机，无付费调用。
- 真实质量存在明显限制：用户积分截图上标误读但标了不确定；Hölder 截图输出超过上限被拒绝；错误积分等式两次检查均未发现错误。后者约 2.8–5.2 秒。本地模式标为实验，不能宣称适用于可靠复杂数学识别/校对。用户截图和结果只保存在被忽略的本机实验目录，没有提交或打包。
- DeepSeek 按官方支持图像的 `deepseek-flash` 接口实现；本机没有其凭据，真实云端调用、费用与样本质量尚未验证。配置与试用步骤见 [AI-SETUP.md](AI-SETUP.md)。本次不代表完成 Android/Harmony 原生安装包或商城验收。

## 实验入口

在本机 `D:\note` 运行 `.\Start-MathInk.ps1`，打开默认地址 `http://127.0.0.1:8787`。开发源代码热更新使用 `pnpm dev:demo`，默认地址为 5173。

平板连接同一 Wi-Fi，运行 `.\Start-MathInk.ps1 -Lan`，用浏览器访问终端打印的电脑地址，在设置中填写配对令牌。浏览器实验可用来检查交互和备份，不替代原生客户端笔感验收。设备数据各自保存，使用完整 JSON 备份搬移实验笔记。
