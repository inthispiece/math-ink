# 开发预览隐私说明

普通书写、分页、手工编辑、检索和导出在设备上进行，不需要模型账号或密钥。笔记、每页原稿、自动保存的草稿及去重来源快照保存在浏览器 IndexedDB；服务配对令牌和界面设置保存在 localStorage。任务只保存原服务与主体标识，不保存供应商密钥。清理浏览器或卸载应用可能删除本地数据，请先导出完整备份。

启动笔记库、普通选择和圈选本身不上传。只有用户在工具内核对发送范围并明确提交后，选区识别才发送所选 PNG；整页识别单独展示并授权当前完整一页图片，包含视口外内容，不沿用选区授权。公式检查只发送所填 LaTeX 和条件；上下文检查与整理只发送选择的正式块或草稿内容；关联建议只包含勾选笔记中的有限候选块。证明辅助只发送展示的目标、假设和已有步骤。每次展示本次范围，没有自动读取整本笔记。供应商密钥仅在服务端，本地手工草稿和数学工具不使用云调用，模拟结果不会当成真实识别。

Ollama 后端只允许电脑回环地址，每次生成前检查视觉能力和远程模型标记，拒绝云模型及远程别名，不会在本地失败后自动转云端。电脑与平板之间通过用户配置的网关传输所选数据。第三方云端的处理地区、保留方式和账户条款需在正式发布前依据实际合同确认。取消等待不能保证供应商撤销已开始的计算。

网关 SQLite 保存请求/安装/账号关联散列、时间、任务状态、用量、次数、费用预留和对账审计，不保存图片、LaTeX、检查条件或页面正文。结果最多在服务器内存缓存 24 小时、最多 1,000 条；重启或过期后正文可能不可恢复，不能自动重复收费生成。重新打开或查询只读取原任务；切换模型不把旧任务改发其他供应商。原账号/连接失效时等待用户恢复，明确重做可能再次计费。同步文字公式检查中断后也不自动重新提交。供应商可能保留计费或审计元数据，不能表述为零记录。

识别结果保存成功即进入原笔记的独立草稿箱。核对、插入与保存分开，模型结果不会自动写入正文。草稿及来源快照由本机持久化；Markdown、LaTeX 和思源普通导出只包含正式内容，不包含未插入草稿、任务及私有快照。**完整 JSON 备份包含草稿箱、原稿快照、用量和任务恢复标识**；分享前请检查这些材料，也可在草稿详情明确单独导出。完整备份不包含服务凭据或账号会话。

笔记或草稿移入回收站后仍保存在设备，可恢复；软删除笔记的晚到结果只留在其回收状态，不会重新带回首页。永久删除笔记保留最小 tombstone 标记防止晚到结果复活，本机不再收取结果；服务端已开始的计算和既有元数据不会因此自动删除或撤销计费。来源页删除不会清除其他草稿或已插入对象仍引用的快照，未被引用资源在明确清理时才删除。备份升级保留旧格式恢复材料，它也可能含私人内容，应与完整备份同等保管。

托管账号数据库另保存用户名、密码的 scrypt 散列、会话和邀请的散列及过期/撤销信息。密码不以明文保存，原始邀请码和会话令牌不入库。浏览器账号令牌仅保存在当前标签页 sessionStorage，按网关地址隔离，不放进笔记备份。退出会撤销本次会话，管理员可禁用账号或撤销全部会话。此身份不自动上传或同步设备笔记；不同入口的迁移需要用户主动导出、导入并核对。

默认不包含广告、用户追踪或自动上传私人笔记的故障报告。导出备份、提交问题及分享笔记由用户决定。公开运行识别服务时需自行提供运营者联系方式、保留/删除规则和正式隐私政策。

正式上架前补充服务主体、联系方式、数据处理地区及备案信息；此开发说明不能替代最终商城隐私政策。
