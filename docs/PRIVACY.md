# 开发预览隐私说明

写字、整理和导出在设备上进行。实验笔记保存在浏览器 IndexedDB；服务配对令牌和界面设置保存在 localStorage。清理浏览器或卸载应用可能删除本地数据，请先导出备份。

模拟识别返回预设公式。真实识别由用户主动圈选并同意后发送 PNG 到配置的网关，再发送至 Mathpix。不会自动上传整本笔记。Mathpix 服务条款、处理地区与保留方式需在正式发布前依据实际账户和合同确认。

网关的 SQLite 仅保存请求/安装标识的哈希、时间、状态及额度信息，不保存图片或 LaTeX。识别结果最多在服务器内存缓存 24 小时、最多 1,000 条，用于同请求返回；重启或过期后消失。供应商可能保留计费或审计元数据，不能表述为零记录。

默认不包含广告、用户追踪或自动上传私人笔记的故障报告。导出备份、提交问题及分享笔记由用户决定。公开运行识别服务时需自行提供运营者联系方式、保留/删除规则和正式隐私政策。

正式上架前补充服务主体、联系方式、数据处理地区及备案信息；此开发说明不能替代最终商城隐私政策。
