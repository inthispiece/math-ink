# 开发预览隐私说明

写字、整理和导出在设备上进行。实验笔记保存在浏览器 IndexedDB；服务配对令牌和界面设置保存在 localStorage。清理浏览器或卸载应用可能删除本地数据，请先导出备份。

「查看固定样例演示」完全在本地返回预设公式，不读取笔迹内容、不上传选区、不消耗真实额度。选区转写只发送圈选 PNG；整页工作台单独展示并授权当前完整页图片，不沿用选区授权。上下文检查与整理只发送用户选择的本段或本页内容；关联建议只包含勾选笔记中的有限候选块。证明辅助只发送展示的目标、假设和已有步骤。上传范围每次展示，没有自动读取整本笔记。供应商密钥仅在服务端，切换供应商不会继承不适用的旧授权。

Ollama 后端只允许电脑回环地址，每次生成前检查视觉能力和远程模型标记，拒绝云模型及远程别名，不会在本地失败后自动转云端。电脑与平板之间通过用户配置的网关传输所选数据。第三方云端的处理地区、保留方式和账户条款需在正式发布前依据实际合同确认。取消等待不能保证供应商撤销已开始的计算。

网关 SQLite 保存请求/安装/账号关联散列、时间、任务状态、用量、次数、费用预留和对账审计，不保存图片、LaTeX、检查条件或页面正文。结果最多在服务器内存缓存 24 小时、最多 1,000 条；重启或过期后正文不可恢复，不能自动重复收费生成。任务进度、已收到草稿、建议和来源图片保存在设备本地，并进入设备完整备份。供应商可能保留计费或审计元数据，不能表述为零记录。

托管账号数据库另保存用户名、密码的 scrypt 散列、会话和邀请的散列及过期/撤销信息。密码不以明文保存，原始邀请码和会话令牌不入库。浏览器账号令牌仅保存在当前标签页 sessionStorage，按网关地址隔离，不放进笔记备份。退出会撤销本次会话，管理员可禁用账号或撤销全部会话。此身份不自动上传或同步设备笔记；不同入口的迁移需要用户主动导出、导入并核对。

默认不包含广告、用户追踪或自动上传私人笔记的故障报告。导出备份、提交问题及分享笔记由用户决定。公开运行识别服务时需自行提供运营者联系方式、保留/删除规则和正式隐私政策。

正式上架前补充服务主体、联系方式、数据处理地区及备案信息；此开发说明不能替代最终商城隐私政策。
