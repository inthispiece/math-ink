# 开通真实手写公式识别

当前预览默认不附带可用的识别账户。“查看固定样例演示”只演示纠错、排版和整理，不读取笔迹，不上传图片，不限次数。主按钮只接受真实识别服务的结果，不会拿演示公式替代笔迹。

## 1. 开通 Mathpix OCR API

1. 打开 [Mathpix 控制台](https://console.mathpix.com)，注册或登录。
2. 创建 OCR API organization，按控制台提示设置付款方式并激活 API。应选择开发者 OCR API；个人 Snip 订阅不能代替 API 凭据。
3. 进入 API keys，复制 `app_id` 和 `app_key`。[官方鉴权步骤](https://docs.mathpix.com/guides/authentication)
4. 在账户隐私设置中关闭 Improve Mathpix。本服务的每次请求也携带 `improve_mathpix: false`。

核实日期：2026-10-23。官方价格页列出首次 API 激活费 $19.99（附 $29 测试额度），普通图片首档 $0.002/张，按用量计费；超过 12 行的图片可能按文档页收费。请在付款前核对控制台及[官方实时价格](https://mathpix.com/pricing/api)。这不是随应用免费提供的识别额度。

## 2. 只在电脑服务端填写密钥

这台电脑已准备 `D:\note\.env`，用本地文本编辑器打开，填写：

```dotenv
OCR_PROVIDER=mathpix
MATHPIX_APP_ID=你的app_id
MATHPIX_APP_KEY=你的app_key
```

其他电脑首次配置可复制 `.env.example` 为 `.env`。不要覆盖已有凭据，不要在聊天、GitHub、浏览器的“局域网配对令牌”栏中粘贴供应商密钥。`.env` 已被 Git 忽略，也不会放入发布包。

关闭旧服务，在 `D:\note` 运行：

```powershell
.\Start-MathInk.cmd -Lan
```

电脑强制刷新页面；平板打开启动窗口里的配对链接。在“识别与设备”中检查连接，页面应显示“mathpix · 真实识别已配置”。“已配置”只表示服务端存在凭据，首次实际识别仍可能因账户未激活、网络或密钥无效而失败。完成上传同意后再试自己的公式。

## 3. 本地额度和供应商额度分别计算

旧版本的每设备每天 10 次、服务每天 200 次、每月 2,000 次是本项目预设的成本上限，并不是 Mathpix 免费额度。旧版本错误地让 Mock 也扣这些次数，现已修复；本地演示不再扣额。

当前 `.env.example` 提供开发配置：

```dotenv
OCR_INSTALLATION_DAILY_LIMIT=200
OCR_GLOBAL_DAILY_LIMIT=1000
OCR_GLOBAL_MONTHLY_LIMIT=10000
```

三个限制分别约束“这个浏览器安装实例每天”“所有实例合计每天”“所有实例合计每月”；任一用完都会暂停真实识别，保留书写和原稿。可自行修改并重启服务；扩大数值会扩大潜在付费调用量。未使用该配置文件时，代码保守默认值仍为 10 / 200 / 2000。

设置中可查看已用量、剩余和重置时间，默认时区为 Asia/Shanghai。额度在调用供应商之前扣减；同一请求标识的重试不重复扣额。已提交但识别失败或超时的调用可能仍被供应商计费，所以不自动退还本地额度，也不自动重新发送。无效图片、未配凭据、拒绝上传不扣额。供应商余额、速率及计费记录请在 Mathpix 控制台查看。

旧数据库会保留；旧记录缺少供应商分类，保守计入真实额度，直到周期重置。升级不会删除笔记或账目，新模拟请求不计入真实额度。

## 4. 复杂公式的验证范围

识别的目标是原样转写，不求解、不补积分限、不按数学常识纠正不等号。适配器保留供应商返回的范数、上下标、矩阵和多行 LaTeX；低置信度候选供用户对照修改。

已经验证的是响应解析、渲染和故障处理，没有用真实账户测得识别准确率。开通后先用不定积分、Hölder 范数、矩阵、多行推导等原始笔迹建立测试集，记录无误率和修正时间；不能用固定样例或合成接口回归宣称识别准确率。
