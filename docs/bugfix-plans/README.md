编号规则：

- 新的一批修补或更新递增计划编号；下一批使用 `BUGFIX-003`，各自从文档 `v1.0` 开始。
- 同一批的补充或调整保留文件名与编号，提升为 `v1.1`、`v1.2` 等，并在文档末尾记录变更。范围整体重写时提升主版本。
- 问题编号使用 `BF001-01` 这样的固定形式，方便测试、提交和后续反馈引用。
- 状态依次为待实施、实施中、待验收、已验收；完成定位或写好计划不等于修复完成。
- 每批实施完成后补充实际代码提交、构建版本、验证结果和未解决问题，不以计划版本代替软件发布版本。
