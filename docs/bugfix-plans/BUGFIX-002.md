## BF002-01 PDF 导入和导出

### 导入流程

笔记库提供“导入 → PDF”，选择文件后预览页数、页面缩略图及导入范围，默认全部页面，文件名作为新笔记名。笔记内部“更多 → 导入 PDF”默认追加到当前页之后，也允许选择新建笔记。导入前明确展示目标位置。

每张 PDF 页对应一张稳定 ID 的笔记页，保留页序、原始尺寸和旋转方向。原 PDF 页作为固定底图，用户可以在上面手写、插入公式、选择和移动自己添加的内容。普通套索不移动或擦除 PDF 原文；原文要变成可编辑的段落与公式，需要另外调用整页或整文档识别，导入不自动发起识别。

导入支持普通文字 PDF 和扫描 PDF。首版保留页面的可见外观，不承诺保留表单交互、脚本、签名验证或恢复原 PDF 的内部编辑结构。需要密码的文件显示明确提示；本批先不开放加密文件导入，不能导入成空白页后宣称成功。

### 导出流程

笔记库的笔记三点菜单和笔记内部“更多”都提供“导出 → PDF”。默认导出全部正式页面，可选择页码范围；预览包含页数、纸张、方向、底纹和输出质量。导出按当前可见 `pageOrder` 排列，包含手写页、PDF 批注页和排版页，排除已删除页面、未插入草稿、任务详情和编辑按钮。

页面输出规则如下：

| 页面类型 | 输出规则 |
| --- | --- |
| 导入的 PDF 页 | 保留原页面尺寸与旋转，合成当前可见批注和公式 |
| 普通手写页 | 使用明确的纸张尺寸，首版默认 A4 竖向；既有超出纸面范围的内容提供完整范围预览和缩放适配，不能静默截断 |
| 识别排版页 | 中文、英文、行内及独立公式按阅读顺序输出；长内容按段落或公式块续页，避免把整张长页压成一张不可读的小图 |
| 空白页 | 默认保留，维持文档页序；预览中可明确选择排除 |

笔记里的逻辑页与 PDF 的物理页数可能不同，例如一张很长的排版页导出为两张纸。预览应显示实际输出页数并保留原页归属；不为导出分页而修改笔记本身。

首版以视觉保真为必须达到的目标：文字、公式、笔迹、图片和底纹清晰完整。优先保留原 PDF 页面内容并叠加批注；确需栅格化的输出明确标为图片模式，不能宣称可搜索、可复制文字或无损矢量导出。可搜索文字层和可编辑 PDF 不是本批的交付前提。PDF 用于阅读和分享，继续保留完整 MathInk 备份作为可恢复编辑状态的格式。

### 实现要点

- 当前宿主没有 PDF 导入导出入口。Butterfly 上游虽有 PDF 能力，现有宿主桥接尚未开放；上游 PDF 导出会先渲染图片，不能直接当作高保真矢量导出。实验画布与 Butterfly 都要完成宿主流程和实际文件验证。
- 新增独立的二进制资源存储，以资源 ID、内容哈希、MIME、大小关联原 PDF；页面保存原文件页索引、尺寸、旋转和坐标变换。已有 PNG/JPEG 原稿快照保持独立，不把 PDF 字节塞进缩略图字段。
- 原文件保留一份，逐页解析、按需渲染和缓存；切换页面释放不需要的高清缓存。导入前按文件大小、页数和设备内存给出限制，取消或失败清理本次临时资源，不留下半篇成功笔记。
- 保存导入资源和页面清单后才显示成功；追加导入失败不能破坏原笔记。批注层与底图使用同一坐标系，缩放、旋转、识别取图和导出均复用该映射。
- PDF 输出使用专门的页面渲染与分页流程，不复用目前长边约 2,048 像素的识别快照作为唯一输出。固定质量档位对应渲染尺寸，中文字体与 PDF 所需运行资源随应用离线打包。
- 导出先保存并冻结本次文档版本；写入失败时保留可导出的内存内容并明确状态。导出期间的新编辑不混入一半旧、一半新的输出。

### 验收要求

无 AI 配置、已完成应用离线资源缓存时，仍可导入本地 PDF、逐页批注、重开和导出。覆盖中英文、数学公式、扫描图、空白页、横竖混排与旋转页；检查页数、尺寸、顺序及批注位置。选页导入、重排、删除及完整备份恢复后，原 PDF 页与来源仍正确。大文档按需加载，不能一次展开全部高清页导致平板失去响应。

## BF002-02 识别排版页的编辑模式

### 按钮位置和默认行为

识别结果加入正式排版页后，顶部工具栏按“撤销 → 重做 → 编辑模式”排列。按钮使用开关状态和明确名称：默认未选中，点击进入编辑，再次点击退出。工具栏拥挤时保留这三项的相邻顺序，其他低频工具收进更多菜单。

本按钮只在由识别结果生成的正式排版页出现，包括单页草稿加入的页面，以及整文档识别另存或插入产生的每一页。普通手写页、未识别的 PDF 批注页不显示此按钮。这里的“每一页默认都有按钮”指功能入口存在，**不表示默认进入编辑状态**。

| 状态 | 页面表现 |
| --- | --- |
| 阅读状态，默认 | 只显示正文、公式、图片与必要页码；隐藏每块的“编辑”“返回此块原稿”、添加段落按钮、编辑边框及拖动手柄 |
| 编辑状态 | 显示可编辑区；选中内容块后，在附近显示编辑、查看原稿等操作，避免每个块都常驻一整排按钮 |

进入编辑不会改写内容；退出时提交当前有效编辑并保留阅读位置。尚有未完成输入或保存失败时，明确显示保存状态并保留编辑现场，不能通过隐藏面板丢弃文本。完成内容修改后再切回阅读，版面不应因残留空按钮占位而出现大块空隙。

### 状态与兼容

- 编辑开关属于界面状态，不产生内容修订、不进入撤销历史。本批补齐正式排版块编辑、增删和移动的内容历史，不能假定现有笔迹/插入历史已覆盖；在阅读状态点击撤销，也能撤销刚才对本页的实际编辑。排版内容由宿主记录，Butterfly 原生笔迹操作仍由原生历史处理，避免一次操作被重复撤销。
- 切页或重新打开笔记时，识别排版页默认回到阅读状态。切页前先保存或结束有效编辑，保存失败沿用现有阻止离开的机制。
- 新页面记录明确的识别来源类型和任务/草稿关联。旧识别排版页通过现有插入记录、草稿类型和来源关系迁移识别；无法确定来源时不凭页名猜测。旧“原有整理内容”页仍保留原来的编辑入口。
- 来源关系仍完整保存。阅读时隐藏逐块来源按钮，编辑时可定位对应原稿；原笔记不存在时展示保留的历史快照，不跳到同页码的其他页面。
- CSS 隐藏之外还要停用对应点击、键盘焦点和快捷键入口。导出使用正文渲染器，始终排除编辑控件，不受导出时是否处于编辑状态影响。

### 验收要求

首次打开、切页、重开及另存生成的识别排版页均默认干净阅读。编辑开关紧邻重做且只在适用页面出现。进入编辑、修改公式和段落、退出、撤销/重做、重开，内容及保存状态正确；隐藏按钮不能再被 Tab 聚焦或意外触发。长页退出编辑后不跳回顶部。

## BF002-03 识别整个文档

### 统一入口与发送范围

入口分别为“我的笔记 → 笔记三点菜单 → 识别整个文档”和“笔记内部 → 更多 → 识别整个文档”。两处使用同一任务流程；在笔记库启动时不要求用户先逐页打开。当前两处菜单已共用宿主菜单函数，可以共用能力检查和任务入口。

提交前保存当前编辑，展示本次页序、总页数、待识别页数、模型服务和发送范围。整篇默认包含当前全部可见正式页面，不含回收页、草稿箱或隐藏任务资料。批次按以下规则处理，结果保持原逻辑页序：

- 手写页和 PDF 批注页：使用完整页面快照，包含视口外内容和当前可见批注，不包含套索框、工具条或编辑按钮。
- 已有排版页：直接复制当前正式结构内容，不重复截图识别，不产生该页的模型费用；确认页明确列出这类页面。
- 确认无内容的空白页：保留空白位置并跳过模型调用；不得把含淡色笔迹或仅有图片的页误判为空白。

先冻结页清单、页 ID、顺序及内容版本，再分批准备输入。冻结内容来自同一可恢复的文档版本，不能在用户继续写字时读取不断变化的页面。对 Butterfly 先保存并枚举完整原生文档，不只处理曾经打开过的页；当前桥接只渲染已加载页，需增加从冻结文档进行独立渲染的会话或等价能力，后台取图不得把前台正在书写的页面切走。实验画布则读取冻结的笔迹、公式实例和底图数据。

DeepSeek 继续作为整文档识别主线。仅当选中的后端明确支持整页结构化识别时开放提交；Qwen 保持可选能力，未实现整页任务时说明不可用，不自动切换云端或伪造批量支持。本批先实现完整逐页转写，不把跨页推理、自动纠错和证明补全混入识别。

### 批量任务与结果保留

新增一个文档级父任务管理逐页子任务，不能只是循环点击现有“识别整页”。每页记录稳定输入、原请求 ID、原服务身份、生成状态、保存状态、结果与费用信息。当前 `Draft` 的单一 `sourcePageId` 不足以表达整篇结果，需要增加多页来源与逐页结果结构。

现有任务管理会在提交前创建草稿，收到结果后保存到该草稿，内存中的已收到结果也不等于持久暂存。本批新增独立的文档任务及结果存储，保留原始响应、解析版本和归档回执；不能靠隐藏自动创建的草稿来冒充“尚未选择去向”。

首版按页串行提交，并为后续受控并发保留接口；页面完成顺序与输出页序分开处理。显示“已完成 7/20 页、失败 1 页、待处理 12 页”及正在执行的页；读取原请求、模型生成和本地保存分别呈现。每页发请求前持久化请求 ID 与输入快照，收到响应先保存原始结果，再解析为排版内容；不等全部结束才写入。解析失败仍可查看错误和导出原始结果，不要求重新识别。

识别完成后的结果暂存在可恢复的任务结果区，笔记库卡片和笔记内更多菜单均可再次打开。此时尚未创建正式新笔记，也不把每页自动塞成许多草稿。结果区可预览全篇，提供以下两个主要操作：

| 操作 | 结果 |
| --- | --- |
| 加入草稿箱 | 在原笔记中生成一条“整文档识别”多页草稿；内部按页浏览、核对与编辑，保留每页来源；可明确选择将全部或指定页面加入原笔记的排版页 |
| 另存为新的笔记 | 输入名称和文件夹，默认名称为“原笔记名 · 识别版”、默认沿用原目录；创建独立笔记，每个结果页成为一张具有编辑模式按钮的正式排版页 |

两种归档方式都使用当前已经收到的结果，不再次识别。操作完成显示去向，用户可主动打开，后台完成本身不抢焦点。归档前关闭结果面板不会丢失结果；只有完成可靠归档并经资源引用检查，或用户明确删除结果后，才能回收暂存数据。

每次归档冻结结果版本，幂等标识由批次、结果版本和归档操作 ID 组成；双击、重试保存或重复回调只生成一份对应产物。之后主动“另存副本”才生成新的独立笔记。先存草稿再另存笔记不互相覆盖，修改任一产物也不联动其他副本；部分结果归档后补齐失败页，用户可明确归档新版本，不能被旧回执阻止，也不自动补写旧副本。

### 失败、重试及另存的数据边界

- 中断后查询原子任务，已成功页直接复用；未知状态先查询，不把断网、刷新或切换模型当成重新生成的理由。服务结果已过期时明确告知，用户选择重新识别失败页才新建调用。失败页重试默认沿用本批冻结快照；改用后来修改的原稿须明确创建新输入版本，不能悄悄混入旧批次。
- 提供暂停后续页面和取消剩余页面。已经开始的服务任务可能继续执行并计费；本机暂停不伪称服务已取消。保留已完成结果和失败原因，支持按失败页明确重试。
- 到达次数、金额或服务限制后暂停后续提交。发送前按待识别页估计需求，金额只能按现有配置给出估算或保守预留，不能将页数当成固定账单。保存失败只重试本地写入，沿用 BF001-01 的未保存结果预览和导出恢复机制。
- 部分页失败时显示“部分完成”，不宣称整篇成功。允许用户明确保存部分结果，失败页在原位置保留带说明的原图占位，不静默缺页或重排；这些页仍具备排版页编辑模式，可手工补录。
- 另存笔记重新分配笔记、页面、块、公式和实例 ID，复制所需原稿快照并重映射内部引用。扩充当前来源结构，显式关联本地历史快照资源；原文档的笔记/页身份作为外部来源信息保留，不能改写成“原稿来自新笔记”。原笔记删除或源页面修改后，新笔记仍可阅读、编辑和查看本次识别的历史快照。后续失败页重试不自动覆盖已另存笔记或已插入实例中的人工修改。
- 不复制原笔记账号凭据、其他草稿或无关任务。不沿用当前单页 `insertDraftPage()` 把多个来源页合并到一张页面的逻辑，需要独立的批量页导入事务，保留页界限并防止悬空资源引用。
- 批量插入原笔记作为一次明确操作记录到宿主页面历史；撤销仅移除此次新增的排版页，保留草稿和结果。另存属于笔记库操作，删除新笔记走回收站，不让旧页撤销误删除另一篇笔记。
- 任务运行时原笔记被软删除，结果保留在其回收状态下；永久删除则取消剩余提交，删除关联批次和暂存结果，并回收无其他引用的资源。删除标记拦截迟到回调和旧编辑器保存，已另存的独立笔记及其所需资源继续保留。浏览器或平板挂起时不承诺持续调度，恢复后按原任务接续。

### 验收要求

两处入口对同一文档展示相同范围。含手写、PDF、已有排版和空白页的混合文档，输出页序及来源一一对应；包含未访问过的 Butterfly 页。关闭面板、切页、继续写字及刷新后可以恢复；模拟乱序返回、单页失败、存储满、服务过期和配额不足，不重做成功页、不覆盖新笔迹。

分别验证整篇草稿、另存新笔记、从草稿批量插入、撤销批量插入及重复点击。新笔记所有结果页均有编辑模式且默认关闭；删除原笔记后，新笔记中的正文、图片和历史快照仍完整。整文档草稿和暂存结果都纳入完整备份恢复。

## BF002-04 笔记库文件夹

首版采用单层文件夹，满足按课程、项目或主题归类；多层嵌套不作为本批前置条件。首页保留“全部笔记”总览，并提供“未分类”和文件夹入口；全部笔记中仍能找到已经归档的笔记，文件夹视图显示当前位置及返回入口。

1. 首页新增“新建文件夹”，输入名称后即可进入。支持重命名；同层重复名称提示调整，标识使用稳定 ID，不依赖名称。
2. 笔记三点菜单增加“移动到文件夹”，可选择已有文件夹、新建文件夹或移回“未分类”。每篇笔记首版只属于一个文件夹，移动不复制笔记。
3. 桌面可拖动笔记卡片到文件夹；平板使用长按后拖动，普通滚动不启动拖拽。目标文件夹高亮，松手才提交，拖到无效区域或取消则保持原归属。菜单始终作为等价操作入口。
4. 文件夹内新建笔记默认归入该文件夹；复制笔记、PDF 新建导入及识别另存默认继承当前或源笔记目录，并允许在创建界面调整。
5. 移动成功提供短暂撤回入口。移动、重命名文件夹不改变原稿修订、页面 ID 或内容最近编辑时间；正文保存和后台任务不能把刚移动的笔记移回旧目录。
6. 删除文件夹默认将其中笔记移回未分类，不删除笔记；操作界面明确这一结果。笔记进入回收站仍保留原归属，恢复时文件夹已不存在则进入未分类。

存储新增独立 `Folder` 元数据和可空的 `Note.folderId`。目录移动用同一仓储事务完成引用校验与更新；拖入和菜单移动调用同一操作。撤回移动前校验笔记仍处于该操作的目的地且归属版本匹配，不覆盖后续移动。删除目录与现存及回收笔记的归属调整在同一事务完成；迟到的拖放、新建和识别另存重新核验目标目录，目录消失时提示选择未分类，不能写入悬空引用。

完整备份包含空文件夹和归属，单篇备份携带所需归属信息；导入冲突按 ID 和明确映射处理，不因名称相同自动合并。

验收覆盖新建空文件夹、重命名、菜单移动、鼠标拖入、触摸长按拖入、取消、撤回、删除目录和回收恢复。旧备份导入的笔记进入未分类，重开及备份恢复保持目录；后台识别完成和旧编辑器保存不回滚归属。搜索默认能查全部笔记，在文件夹内明确显示当前筛选范围。

## BF002-05 滑动翻页与缩放反馈

### 滑动翻页

横向滑动用于翻页：向左下一页，向右上一页；纵向手势继续用于阅读长页或平移。保留原有上一页、下一页和页码按钮，首末页显示边界反馈，不循环也不自动新建页面。

为了与现有书写和套索共存，首版采用下列仲裁规则：

| 输入场景 | 行为 |
| --- | --- |
| 阅读或平移状态，纸面已适配可视宽度 | 单指明确横滑翻页，纵滑滚动；一次手势最多翻一页 |
| 页面横向放大溢出 | 单指先平移；到达纸面横向边界后，必须抬手重新发起向外横滑，才允许翻页 |
| 触笔输入、手指书写开启、套索变换或公式放置中 | 纸面手势继续操作内容；页面下方导航区域提供单指横滑翻页，避免把笔画或移动误判为翻页 |
| 双指捏合或双指平移 | 全程只缩放和平移，不能在松手时额外触发翻页 |

翻页候选使用方向、距离、移动速度及触点数量判断，在手势结束时提交。出现第二指、笔输入、内容变换、弹窗或手势取消时立即取消翻页候选，不在一次手势中从缩放切成翻页。起始于系统边缘后退区域的手势交给系统；拖拽内容、选择文字及点击按钮不参与翻页识别。

下方导航区域也遵守内容操作锁：触笔仍按下或套索变换未结束时不启动翻页。公式放置预览须先明确取消，已提交放置或正在保存时等待完成；不能借切页静默取消半次内容操作。

翻页统一走现有切页保存流程和导航锁：当前编辑落库成功后才切页，失败留在原页并显示重试/导出。快速连续滑动不能重复执行、跨过页面或把未保存内容写到下一页。纸面边界使用统一的文档页面几何，不以当前笔迹包围框临时推算。

### 缩放百分比与双击

缩放时在当前纸面下方居中显示百分比，例如“125%”。双指缩放、滚轮缩放、按钮缩放和恢复视图都使用引擎真实视图值；操作结束后短暂保留再淡出，可点击该读数恢复 100%。显示层不遮挡内容，也不进入截图或 PDF。

手指在纸面空白或非交互区域双击，恢复本页逻辑 100% 并将纸面居中；桌面空白处双击提供同等行为。排除文字选择、公式编辑、按钮、选区手柄及触笔书写，双击期间不能留下两个点状笔迹。手指书写开启时保留其笔画语义，可从页面下方百分比控件完成同样的复位。

100% 定义为统一页面基准比例 `zoom = 1`，与设备像素比无关，不代表实际纸张的厘米尺寸。“适合纸面”继续是独立操作，按可用区域计算比例，不能再把 Butterfly 的 `zoom = 1` 当作适合纸面。横竖屏切换重新计算适配比例，但不悄悄把用户手动缩放强制改为适配。

每页分别保存缩放与位置。排版页新增独立视图变换，滚动偏移与画布平移不能混用同一字段解释；PDF 页也通过同一视图适配接口显示百分比。视图变化不进入内容撤销、不改变笔迹、公式大小或原稿修订；保存视图采用节流，不每帧写整篇笔记。

### 双引擎实现与验收

实验画布目前已有捏合和滚轮视图操作，需要补充翻页仲裁与复位命中检测。Butterfly 位于 iframe，宿主不能靠透明覆盖层截获手势；增加原生视图变化、可翻页意图和复位事件，携带笔记、页面、会话及手势代次，宿主拒绝旧页面事件。翻页后取消旧页惯性移动，实时百分比不通过反复保存整个原生文档获取。

分别验证手写页、PDF 批注页及识别排版页：单指翻页、放大后平移到边缘、双指缩放、双击复位、套索拖动、公式放置、长页滚动和保存失败。安卓/鸿蒙平板横竖屏下实测，不以桌面鼠标自动化代替触笔、掌触和多点触摸验收。

## 数据迁移和共用模块

以当前 schema 3 为基础，本批规划新的数据库和备份格式版本，暂定 schema 4；实施时确认没有被并行版本占用。升级事务保留迁移前恢复材料，失败回滚；继续导入 schema 1/2/3，不要求用户清空本地数据。

备份不携带服务密钥或登录凭据。恢复批量任务后先校验原服务身份、请求 ID 和远端状态，未提交页面须由用户明确继续；导入备份本身不自动触发模型调用，也不重放已经完成的请求。

| 模块 | 需要增加或调整的边界 |
| --- | --- |
| 页面与资源 | PDF 资源引用、纸张尺寸和旋转；识别排版页来源类型；统一视图几何 |

资源清理必须同时考虑正式页、草稿、任务暂存、来源快照和回收站引用。仅从某张页面移除引用，不代表原文件已经无人使用。完整备份在只携带新笔记时也须包含其阅读和历史来源所需材料。
