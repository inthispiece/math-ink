# MathInk · 数学手写笔记

我的笔记 → 多页书写与 PDF 批注 → 按需识别 → 草稿或独立识别版 → 对照原稿核对 → 明确整理。

## 本地运行

需要 Node.js 24 和 pnpm 11.25.0。首次克隆主仓库即可运行实验界面，无需下载整个上游源码。

```powershell
git clone https://github.com/inthispiece/math-ink.git
cd math-ink
pnpm install --frozen-lockfile
pnpm dev:demo
```

打开终端显示的 `http://localhost:5173`，先进入“我的笔记”。点击“新建笔记”即可书写，用“新增页”和页面概览管理多页；返回首页、重开笔记会恢复上次页面和视图。**普通书写不需要模型、账号或密钥，也不产生模型请求。** 当前命令使用模拟网关，真实识别会要求配置真实后端，不会把固定样例当作笔迹识别。无需服务的排版试用可从“工具箱 → 手工创建草稿 → 输入 LaTeX 公式”开始。

若已在 `D:\note`，直接从 `pnpm install` 开始。常用命令：

| 命令 | 用途 |
| --- | --- |
| `pnpm dev:demo` | 无密钥的本机书写、分页、手工草稿实验；不识别真实笔迹 |
| `pnpm dev:ocr` | 使用 `.env` 中配置的真实后端 |
| `pnpm dev:local` | 使用电脑本地 Ollama/Qwen |
| `pnpm local:pull` / `pnpm local:serve` | 下载本地模型 / 启动本地服务 |
| `pnpm dev:lan` | 同一局域网平板实验，终端显示可直接打开的配对链接 |
| `pnpm check` | 类型检查、单元/接口测试、构建 |
| `pnpm test:e2e` | 浏览器完整流程测试，默认使用 Edge |
| `pnpm test:preview` | 已构建 ZIP 的实际解压运行、离线重载和网关验证 |
| `pnpm test:butterfly` | 真实 Butterfly 本地资源、手写、桥接与原稿恢复验证 |
| `pnpm build` | 输出 `dist/web`、思源插件和原生客户端引导资源 |
| `pnpm preview` | 启动已构建的离线资源预览，默认 `http://127.0.0.1:8787` |
| `pnpm package:preview` | 生成可下载预览 ZIP、思源插件 ZIP 和 SHA256 清单 |
| `pnpm doctor` | 查看开发工具是否可用 |

这台电脑已完成构建时，可双击 `Start-MathInk.cmd` 启动本机预览；同一 Wi-Fi 平板实验双击 `Start-MathInk-Lan.cmd`，或在 `D:\note` 运行 `.\Start-MathInk.cmd -Lan`。打开启动窗口显示的地址或配对链接。CMD 入口直接运行 Node，无需调整 PowerShell 执行策略。原 `Start-MathInk.ps1` 仍可使用。GitHub Release 的开发预览 ZIP 只需 Node.js 24，无需安装 npm 依赖。

## 本批功能试用

1. 首页新建文件夹；用笔记菜单“移动到文件夹”或拖入归类，触摸长按后才拖动。删除目录只移回未分类，不删除笔记。
2. 首页“导入 PDF”或笔记“更多 → 导入 PDF”，预览页码范围和新建/追加目标后确认；PDF 是固定底图，笔迹与公式可独立批注。更多菜单导出 PDF 时先生成实际分页预览，再下载；普通手写/排版为图片模式，不承诺全部文字可搜索。
3. 识别结果加入的正式排版页默认干净阅读。重做右侧打开“编辑模式”，选中块后编辑、增删、移动或查看原稿；退出保留阅读位置，实际编辑可撤销。
4. 卡片菜单和笔记“更多 → 识别整个文档”共用任务区。先冻结范围再明确提交；已排版页直接复制，已确认空白页保留，不调用模型。逐页结果先保留在任务区，再选“一条整文档草稿”或“另存新的笔记”，不会自动产生很多草稿或抢走当前页。失败只明确重试对应页，归档复用结果不再识别。
5. 阅读/平移状态可横滑翻页，放大后先平移到边界并抬手再滑；双指只导航。下方百分比可恢复逻辑 100%，空白处双击等价；“适合纸面”是独立操作。笔输入、套索及放置期间不抢内容手势，真机触控与笔感仍待验收。

PDF、目录和普通阅读不需要 AI 配置。整文档主线使用支持整页结构化识别的 DeepSeek，Qwen 尚未开放整页批量任务，不自动切云。详细流程、备份和恢复见 [AI 中文指南](docs/AI-SETUP.md)。

## AI 转写、公式检查与平板实验

在“应用设置 → 识别服务与账号”切换 **DeepSeek 云端、本地 Qwen3-VL-2B、Mathpix**。切换后端无需重启网关；修改服务端 `.env` 后需要重启。“新笔记手写引擎”只决定以后新建笔记的画布，已有笔记保留自己的引擎，避免未转换原稿时显示空白。

在笔记中打开“工具箱 → 识别公式”，圈选后点击识别，核对原图及发送范围，再明确提交。圈选本身不上传。“识别整页”单独预览当前完整一页，包含视口外内容。识别成功即保存到原笔记草稿箱；等待时可继续书写、换页或返回笔记库，结果不抢焦点、不改正文、不自动另建笔记。

从草稿箱核对原图、编辑 LaTeX 或段落，修改会自动保存。标记已核对和插入是独立操作：公式须选择当前手写页上的放置位置，整页草稿须明确加入为一张排版页。每次插入都是独立副本；以后改草稿不会联动旧实例，撤销插入也不删除草稿。“检查公式”、上下文纠错和证明建议在“更多数学工具”中单独调用，只发送本次展示的文字范围，采用建议前不改变原式。

完整配置与操作见 [AI 中文指南](docs/AI-SETUP.md)，应用设置也有离线帮助。

后续开发采用 DeepSeek 云端主线、Qwen 本地可选模式，阶段安排与验收标准见 [AI 开发计划](docs/AI-ROADMAP.md)。

前端交互按“笔记库 → 多页书写 → 按需工具箱 → 笔记内草稿箱”调整，详见 [前端交互改造计划](docs/FRONTEND-INTERACTION-PLAN.md)。

后续反馈按批次编号跟踪，见 [修补与更新计划索引](docs/bugfix-plans/README.md)。[BUGFIX-001 v1.0](docs/bugfix-plans/BUGFIX-001.md) 的验收记录继续保留；[BUGFIX-002 v1.0 功能与交互更新计划](docs/bugfix-plans/BUGFIX-002.md) 是本批 PDF、编辑模式、整文档识别、文件夹及翻页缩放的实施与验收依据，实际进展追加在计划完成记录。

本轮开发预览提供独立笔记库、页面新增/复制/排序/删除/恢复、空白/横线/方格纸、本篇草稿箱及显式插入；原有分块、行内公式、上下文建议、整理、知识关联和证明辅助迁入按需工具。全文检索、人工关联及本地多项式核对可离线使用。证明建议始终未验证，真实页面质量、云端费用与两端笔感尚未验收。

升级前请导出完整备份。新备份采用 **schema 4**，兼容导入 schema 1/2/3；IndexedDB 1/2/3→4 在同一事务保留升级前原格式恢复快照，失败回滚。完整备份包含目录、原 PDF、草稿和整文档暂存结果，同一原文件按唯一资源编码一次；所有笔记备份还包含空目录，不携带服务密钥或登录凭据。目录冲突须明确映射或新建独立名称/ID，同笔记 ID 仍须先备份并确认覆盖。恢复任务先查询原请求，未提交页不自动生成。Markdown、LaTeX 和思源常规导出只保留正式内容与必要来源资产；分享完整备份前检查私有草稿和任务。旧笔迹和“原有整理内容”页继续可访问，登录不自动同步不同域名/IP 的数据。

真实评测工具及 40 道待人工核验检查题见 [evaluation](evaluation/README.md)，运行 pnpm eval:ai --help 查看入口；没有真实云端成绩。托管版的账号、成本保护、运维和 HTTPS 配方见 [部署说明](deploy/README.md)，公网服务器与真实质量评测须另行配置。

- **DeepSeek：** 在电脑 .env 填写 DEEPSEEK_API_KEY，模型默认为 deepseek-flash。设置选 DeepSeek，检查连接后再转写。API 按用量计费，密钥不能填在配对令牌栏。没有凭据不会返回模拟样例。
- **本地 Qwen：** 本机已准备便携运行时及 qwen3-vl:2b-instruct；其他电脑先安装 Ollama，再运行 Setup-Qwen.cmd 下载模型。使用时保持 Start-Qwen.cmd 运行，在设置选本地 Qwen。模型运行在电脑，平板通过网关使用，不扣云端次数，不会自动切云端。
- **Mathpix：** 保留原后端，按 [原 Mathpix 配置步骤](docs/MATHPIX-SETUP.md)填写凭据，可作为识别对照；它不支持本应用的 AI 文本公式检查。

电脑和平板连接同一 Wi-Fi 后双击 Start-MathInk-Lan.cmd，平板打开启动窗口的配对链接。本机页面可自动配对；自动生成的令牌保存在 .local/pairing-token，重启复用，明确环境配置优先。电脑与平板的笔记各自保存在浏览器，不自动同步；建议导出备份。局域网 HTTP 用于受信网络开发，公网使用 HTTPS。

云端转写与检查共用本服务预算，次数由运营者配置及鉴权后的 `/v1/usage` 决定；没有配置覆盖时采用每实例每天 10 次、服务每天 200 次及每月 2,000 次。供应商余额、token 账单和限流另算，本地 Qwen 不扣云端次数。

本轮还增加金额保护：默认每用户每天 5 元、每月 50 元，全服务每天 50 元、每月 500 元。它与次数限制同时生效，可能先达到金额上限。未配置当前模型的价格时，本地实验每次按 0.5 元占用预留，未知费用不自动退回，不能把预留当成实际账单或费用上界；托管版则拒绝未配价格的云生成。运营者可在 `.env` 调整预算并配置核对过的带日期价格，步骤见 [部署说明](deploy/README.md)。

云端每次明确展示发送范围。选区识别与整页任务支持用原任务 ID 查询；刷新或服务中断不会自动重新付费生成，切换模型不改变旧任务的原服务和账号。结果正文过期、服务重启或原连接失效时会说明状态，明确重做才新建调用；同步公式检查中断后可能无法查询。失败和取消保留原稿，已开始的供应商计算仍可能计费。详见 [隐私说明](docs/PRIVACY.md)。升级后若仍显示旧界面，电脑按 Ctrl+Shift+R 强制刷新，无需清除笔记。

## 思源插件和独立客户端

`pnpm build` 后把 `dist/plugin/math-ink` 复制到思源工作空间 `data/plugins/`，在插件设置启用，再打开 MathInk。插件支持通过公开 API 保存原稿资产、公式块和来源属性。在应用设置填识别服务地址；配置服务端允许的思源页面 Origin，并使用配对令牌。

上游源码与双端构建见 [构建说明](docs/BUILD.md)。独立客户端使用自己的包名、协议及本地端口，并内置数学界面；鸿蒙目标为 5.1+，安卓最低 Android 10。安装与手写性能以真机验收为准。

在包含完整资源的预览中，从设置选择“新笔记手写引擎 → 本地 Butterfly”，再新建笔记。已有原稿继续使用原引擎；不会隐式转换。浏览器回归和真实鼠标画布检查的范围见 [开发预览验收记录](docs/DEVELOPMENT-PREVIEW.md)；安卓/鸿蒙真机的笔压、掌触、延迟和后台恢复仍未验收。

## 数据和开源

笔迹、自动保存的草稿及正式内容存放设备本地。完整 `.mathink.json` 备份保留页面、草稿及来源；Butterfly 模式另保留原 `.bfly` 文档。已打开笔记可断网书写和保存；生产预览首次加载并完成离线资源缓存后才能离线重开。识别依赖相应模型服务，不能离线调用云端。
