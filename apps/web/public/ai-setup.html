本轮更新候选 0.1.0-preview.9 对应 BUGFIX-002 v1.0，状态为待验收；BUGFIX-001 的真机验收继续保留，软件回归不能代替目标设备验证。

先写笔记，再按需使用工具

“我的笔记”中新建后即可书写；用新增页和页面概览管理多页、纸张、复制、排序、删除与恢复。返回首页再打开恢复上次页面和视图。工具箱与草稿箱按需打开。普通书写、手工 LaTeX 草稿、检索和本地多项式核对不产生模型请求。

设置中的“新笔记手写引擎”只影响以后新建的笔记；已有笔记保留自己的画布，不隐式转换原稿。已打开笔记可断网书写和保存；生产资源首次成功加载并完成缓存后才能离线重开，云识别仍需联网。

文件夹与 PDF

首页保留“全部笔记”“未分类”和单层文件夹，可新建、重命名。笔记菜单“移动到文件夹”与拖入目录等价；触摸长按后才拖动，普通滚动不移动。无效目标或取消保持原归属，移动后可短暂撤回；已有后续移动时不覆盖它。删除文件夹将笔记移回未分类，不删除笔记，回收站中的归属也一起处理。

笔记库点导入 PDF，或在笔记“更多 → 导入 PDF”选文件。预览页数、缩略图及范围（如 1-3,5），确认新建笔记的名称/目录，或追加到当前页之后。面板会给出大小与页数限制；需要密码的文件本版拒绝，不以空白页冒充成功。导入不调用 AI，PDF 原文为固定底图，套索/橡皮只操作添加的笔迹和公式。

“更多 → 导出 PDF”冻结本次正式版本。选择页码、质量与是否排除确认空白页，先生成输出预览，核对实际纸张数、方向及原页归属，再下载。原 PDF 内容保留并叠加批注；普通手写/排版页为图片模式，不承诺全部可搜索/复制。长排版按块续页，纸面外笔迹完整缩放适配，不静默截断；默认保留空白页，排除回收页、草稿、任务与操作按钮。PDF 用于阅读分享，完整 MathInk 备份才保留可恢复编辑状态。

排版页默认阅读，按需编辑

识别加入或另存的正式排版页默认只显示正文、公式和图片。工具栏按撤销 → 重做 → 编辑模式排列；开启编辑后选中块，才显示编辑、查看原稿等操作。关闭编辑保留阅读位置，切页和重开默认回到阅读。实际块编辑/增删/移动可撤销，开关和视图不记内容历史；保存失败先重试或导出，不能靠隐藏编辑丢弃现场。旧“原有整理内容”页继续提供原编辑入口。

识别整个文档

  1. 笔记库卡片菜单或笔记内部“更多 → 识别整个文档”打开同一任务区。准备只冻结当前可见正式页及版本，未提交模型；先核对完整页序和原服务身份。
  2. 手写/PDF 页发送完整冻结图片；已有排版页直接复制结构，确认空白页保留位置，后两类不生成模型费用。排除回收页和草稿，后台不切走前台书写页。
  3. 勾选本批范围同意后明确提交，按页串行处理。当前整页主线为 DeepSeek；未开放整页的 Qwen 不自动切云。进度分别展示生成、原始响应和本地解析保存，页数不等于 token 账单；额度达到上限后暂停后续页。
  4. 关闭面板、继续写字、切页或刷新后仍可从两处入口重开。恢复先查询原请求，不重做成功页，不自动把结果写成正式笔记或很多单页草稿。
  5. 选择加入草稿箱形成一条按页核对的整文档草稿，再明确加入全部或指定排版页；或填写名称/目录另存为新的笔记。两种去向复用结果，不再识别，副本内容和本地历史原图独立保留。原笔记删除、草稿修改或失败页补齐不会自动覆盖旧副本。

部分失败需明确勾选保存部分结果，失败页在原位置保留原图与说明，可手工补录。暂停只停后续页面，取消不能撤回已经开始的服务计算。未知状态先查询，明确重试失败页才使用新请求和本批旧快照。已收到但存储失败时先导出任务与收到结果，再重试本地保存；任务区“恢复收到的整文档结果”按原任务恢复文件。重复归档同一版本只生成对应一份，另一份须“明确另存一个副本”。

翻页和真实缩放比例

阅读/平移且纸面适配宽度时，单指横滑翻页，纵向继续阅读。放大后先平移，到边界抬手再向外滑才翻页；一次手势最多一页。触笔、手指书写、套索变换和公式放置继续操作内容，可在内容操作结束后使用下方导航区；双指全程只导航，松手不额外翻页。切页先保存，失败留在原页。

纸面下方短暂显示真实百分比，点击恢复逻辑 100%（zoom=1）；空白非交互区域的触摸/桌面双击同样复位。手指书写开启时用百分比按钮，避免误判笔画。“适合纸面”独立按可用宽度计算。每页视图分别保留，不改变公式实例大小或进入正文历史；目标平板的连续手势、旋转、笔压、掌触和延迟仍待真机验证。

DeepSeek 云端

在 DeepSeek 开放平台创建 API key，查看余额与价格。免费聊天账户不等于免费 API。本机开发在电脑 D:\note\.env 配置：

OCR_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的API_Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_TIMEOUT_MS=45000

密钥只放服务端，不填配对栏，不发聊天。关闭旧服务，双击 Start-MathInk-Lan.cmd，刷新页面，平板打开新配对链接。在“应用设置 → 识别服务与账号”选择 DeepSeek 云端、保存并检查连接。连通不代表生成质量；未配置或余额不足报错，不以演示公式代替。

圈选转写与公式检查分开

“识别公式”复用工具栏常规“套索”的有效选区；无选区时提示先选择。圈选本身不上传，纯笔迹选区核对图片后再明确提交；混选笔迹/公式或只选排版公式会拒绝并提示调整。只转写原式，保留积分限、范数、上下标和多行，不求值。独立“检查公式”只发所填 LaTeX 和条件，不附图；明确采用前不改原式，也不自动写正式内容。

常规选择、移动和撤销

套索可选择笔迹与已插入公式，拖动移动、控制点等比缩放；“平移”与双指缩放只改变视图。Escape 在变换中先取消手势并恢复初始内容，平时清空选择。切换笔/橡皮/平移清理选择，晚到识别结果不清掉后来建立的新选区。

实验画布按笔记与页面记录本会话内的笔迹、公式插入/删除/编辑/移动/缩放。一次手势是一条命令，撤销删除恢复同一实例，草稿不回滚。Butterfly 使用当前笔记文档的原生时间线，可能影响别页并提示页码。已执行但保存失败时只“重试保存”，不再重复撤销/重做；不承诺跨应用重启恢复整条历史。

识别自动存稿，插入另行确认

  1. 工具箱选择识别整页，查看页码、当前完整页图片与发送范围再提交。包含视口外内容，不沿用选区授权；先试清晰单栏中英数学笔记。
  2. 成功即自动保存为原笔记的一条草稿，不新建笔记、不增加正式页、不抢焦点。等待时可继续写字、换页或返回首页。
  3. 草稿箱中对照原稿编辑，核对标题、列表、段落、行内/独立公式、推导及疑点；支持拆分、合并、重排和改类型，修改自动保存。关闭详情不丢已保存结果。
  4. “已核对”仅是用户标记，不是数学证明。公式须选择“插入当前页”并点击放置位置；整页须明确“作为排版页加入笔记”，原手写页保留。
  5. 每次插入是独立内容副本。改草稿不改旧实例，撤销插入和删除草稿不移除已插入的其他内容。来源改变或删除仍保留历史快照，并提示对应旧版本。

上下文、整理和建议

更多数学工具或草稿详情中勾选内容块，每次预览范围后确认。只发所选文字/公式，不自动附图或其他笔记。建议显示改前/改后、理由和引用；逐条或勾选采用/拒绝/撤销，相关内容或原稿变化后拒绝覆盖。

整理结果留在本篇草稿箱，保留原条件、公式和来源，不自动新建笔记；摘要与新增解释明确标为 AI 内容。是否加入排版页由用户另行决定。

检索、关联及限定证明工具

本地搜索正文、公式与标签，支持手工链接、反链及准确块跳转。目标变化提示核对，删除提示断链。AI 关联只查看主动勾选的笔记及有限相关块，展示引用和理由，确认才建关系。

证明步骤只试验初等代数/基础微积分，展示假设、已有步骤、下一步和未解决问题，始终标为未验证建议。独立本地多项式工具精确核对有理系数单变量恒等式或候选原函数，例如 x^2 与 x^3/3+C；不联网、不改笔记，不能验证一般定理或整篇 AI 证明。

任务恢复与费用

模型“已收到”与本地“已保存”分别显示。出现“已收到，待保存”时可查看预览、复制或“导出收到的结果”，再“重试保存收到的结果”，不会另发模型请求。存储仍不可用时先导出保护内容，不能假定失败状态本身也能写入。

旧版导出的原始 Reply 不是完整备份。从草稿箱底部 → 恢复收到的结果导入，根据本机原任务 ID、供应商、来源版本和内容结构恢复；不归入恰好打开的另一篇笔记。原任务或导出材料缺失、服务缓存又已消失时，不能保证恢复正文。

本机保存任务 ID 和已收草稿。选区与整页任务重开后只查询原请求，不自动重复付费。切换后端只影响新任务，旧任务按原服务和账号查询，连接失效时等待恢复。服务重启/缓存过期可能没有正文；同步文字公式检查中断也不保证可查询。明确“重做（可能再次计费）”才新建调用。取消不能保证撤销供应商计算；次数、频率、并发和金额保护共同生效，超额仍可写笔记。

默认每用户每天 5 元、每月 50 元，全服务每天 50 元、每月 500 元。未配价格的本地实验每次占用 0.5 元预留，未知费用不自动释放，所以次数仍有剩余也可能触发金额上限。预留不是实际账单或费用保证；运营者可在服务端 .env 配置带日期的 AI_PRICE_CONFIG 并调整预算后重启。托管模式没有当前模型有效价格时拒绝云生成。

本地 Qwen3-VL-2B

电脑运行 Ollama，安卓/鸿蒙平板调用电脑网关，不是平板独立推理。本机已准备运行时及权重，其他电脑先安装 Ollama，运行 Setup-Qwen.cmd 或 ollama pull qwen3-vl:2b-instruct 下载约 1.9GB。

OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3-vl:2b-instruct
OLLAMA_TIMEOUT_MS=180000

保持 Start-Qwen.cmd 打开，再启动 MathInk，设置切换本地 Qwen。固定 2b-instruct；原 2b 思考变体实测可能耗尽输出。Ollama 仅回环连接并拒绝远程云别名，不应暴露公网。

2B 仍为选区实验，复杂公式可能误读、截断或漏检。整页、整文档、上下文、整理、AI 关联及证明任务未在本地开放，会禁用并保留手工入口；不会失败后暗自转云端，不扣云端额度。托管服务器无法访问你电脑回环 Ollama，请主动从电脑/局域网入口使用本地模式。

备份升级及换地址迁移

完整备份和 IndexedDB 为版本 4，兼容版本 1/2/3。保留笔迹、正文、视图、草稿与历史来源，并增加目录、原 PDF 资源和整文档暂存结果；同一原文件按唯一资源编码一次。所有笔记备份包括空文件夹，单篇携带所需目录与附件；不携带服务密钥或登录凭据。同事务保留升级前恢复快照，失败回滚；旧笔记未分类，不经 AI 重写。

完整备份可使用可选资源池，对规范 PNG/JPEG、等价图片字段和重复 Butterfly 原始归档按哈希编码一次；导入校验后还原原字段与独立数组，不改来源身份，不重打包原稿。无资源池的旧版本4仍兼容，不可识别的旧图片原文保留。超出资源或展开上限会拒绝且不改现有库，请按笔记拆分并保留原文件。原始 Reply 和整文档任务恢复 JSON 沿用各自协议。

目录标识或名称冲突时，明确选择现有目录、未分类，或新名称与新 ID，不按名称自动合并。同笔记 ID 仍须先备份当前内容、再明确确认覆盖；恢复批量任务先查询原请求，未提交页必须主动继续。Markdown、LaTeX 与思源普通导出只包含正式页面和必要原稿资产，不混入未插入草稿、任务或私有快照。完整 JSON 备份包含整个草稿箱、PDF 和暂存结果，分享前检查内容；草稿详情也可单独导出。永久删除不能撤回服务器已开始的计算。

  1. 旧入口导出“所有笔记 · 完整 JSON”，保留文件及旧数据。
  2. 新局域网地址/HTTPS 域名恢复完整备份。
  3. 核对数量、正文、公式、原稿及来源，并再导出新备份。
  4. 完成前保留旧数据。浏览器地址不同则存储隔离，登录不等于同步。

托管邀请与真实评测

本机联调用配对令牌，托管用邀请账号及可撤销会话，按可信用户计算额度，用户不用填供应商密钥。实际 HTTPS 域名、服务器、预算和邀请仍需配置。源码提供 scripts/eval-ai.mjs、私人 .local/evaluation 目录与 40 道待人工核验候选题，全部 humanVerified:false。真实调用须显式允许可能付费和预算，默认最多 3 条。无真实页、人工审核或账单则报告未知，不用程序测试冒充准确率。
