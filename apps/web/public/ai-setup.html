整页数学笔记配置与试用

2026-10-24 开发预览提供整页、上下文、整理和关联工程流程。真实 DeepSeek 云端质量评测仍为 0 次，不等于计划准确率、节省时间或费用目标已通过。原稿始终保留，模型内容须核对。

DeepSeek 云端

在 DeepSeek 开放平台创建 API key，查看余额与价格。免费聊天账户不等于免费 API。本机开发在电脑 D:\note\.env 配置：

OCR_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的API_Key
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_TIMEOUT_MS=45000

密钥只放服务端，不填配对栏，不发聊天。关闭旧服务，双击 Start-MathInk-Lan.cmd，刷新页面，平板打开新配对链接。设置选择 DeepSeek 云端、保存并检查连接。连通不代表生成质量；未配置或余额不足报错，不以演示公式代替。

圈选转写与公式检查分开

圈选并“转写为 LaTeX”只发送选区图，保留积分限、范数、上下标和多行，不求值。独立“检查公式”只发当前 LaTeX 和手填条件，不附图。建议单独显示，采用到编辑框后仍须确认整理。原稿不会自动替换。

整页工作台

  1. 顶部点击整页排版草稿，选择当前原生画布页，先试清晰单栏中英数学笔记。
  2. 点击当前完整页 → 排版草稿，核对本次整页图片范围再明确发送。完整页带坐标映射，不是屏幕可见截图；授权不沿用圈选授权。
  3. 逐块对照原稿，核对标题、列表、段落、行内/独立公式、推导、顺序和疑点。不支持图形区域保留原图。可编辑、拆分、合并、重排及改类型。
  4. 公式只有一份可编辑 LaTeX，行内和独立块通过 ID 引用。来源可返回具体原稿位置，手工/导入注明无原稿关联。
  5. 保存、离线重开并核对，再导出 Markdown、LaTeX 或完整 JSON。内容修订与原笔迹修订独立，旧建议不能覆盖新编辑。

上下文、整理和建议

选择本段或本页，先展开“本次上下文范围”再逐次授权。只发送该范围文字/公式，不自动附图或其他笔记。建议分识别疑点、语言、数学和缺少条件，显示改前/改后、理由和引用。逐条接受、拒绝或仅批量接受勾选有效项；相关内容或原稿变化后，旧建议只能查看。

“撤销采用”恢复原内容，但拒绝覆盖后来编辑。整理采用为新整理草稿，保留原篇、公式、条件和来源；摘要与新增解释明确标为 AI 建议。

检索、关联及限定证明工具

本地搜索正文、公式与标签，支持手工链接、反链及准确块跳转。目标变化提示核对，删除提示断链。AI 关联只查看主动勾选的笔记及有限相关块，展示引用和理由，确认才建关系。

证明步骤只试验初等代数/基础微积分，展示假设、已有步骤、下一步和未解决问题，始终标为未验证建议。独立本地多项式工具精确核对有理系数单变量恒等式或候选原函数，例如 x^2 与 x^3/3+C；不联网、不改笔记，不能验证一般定理或整篇 AI 证明。

任务恢复与费用

本机保存任务 ID 和已收草稿，失败、取消、刷新不自动重复付费。先查询原任务，服务重启/缓存过期可能仅有状态、没有正文。已有草稿保留，明确“重做（可能再次计费）”才新建调用。取消不能保证供应商撤回计算。次数、并发、频率和金额保护共同生效，无价格/用量时费用未知，不能按免费释放。超额仍可书写、编辑、保存和导出。

默认每用户每天 5 元、每月 50 元，全服务每天 50 元、每月 500 元。未配价格的本地实验每次占用 0.5 元预留，未知费用不自动释放，所以次数仍有剩余也可能触发金额上限。预留不是实际账单或费用保证；运营者可在服务端 .env 配置带日期的 AI_PRICE_CONFIG 并调整预算后重启。托管模式没有当前模型有效价格时拒绝云生成。

本地 Qwen3-VL-2B

电脑运行 Ollama，安卓/鸿蒙平板调用电脑网关，不是平板独立推理。本机已准备运行时及权重，其他电脑先安装 Ollama，运行 Setup-Qwen.cmd 或 ollama pull qwen3-vl:2b-instruct 下载约 1.9GB。

OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3-vl:2b-instruct
OLLAMA_TIMEOUT_MS=180000

保持 Start-Qwen.cmd 打开，再启动 MathInk，设置切换本地 Qwen。固定 2b-instruct；原 2b 思考变体实测可能耗尽输出。Ollama 仅回环连接并拒绝远程云别名，不应暴露公网。

2B 仍为选区实验，复杂公式可能误读、截断或漏检。整页、上下文、整理、AI 关联及证明任务未在本地开放，会禁用并保留手工入口；不会失败后暗自转云端，不扣云端额度。托管服务器无法访问你电脑回环 Ollama，请主动从电脑/局域网入口使用本地模式。

备份升级及换地址迁移

完整备份为 schema 2，保留稳定笔记/公式/来源 ID、顺序、建议、任务和链接。schema 1 旧 Markdown 原样作兼容块，不经 AI 重写。同来源 IndexedDB 升级先保留恢复快照，失败回滚；可导出升级前备份。无效导入不改原库，同 ID 须先备份再明确确认覆盖，不自动改 ID。

  1. 旧入口导出“所有笔记 · 完整 JSON”，保留文件及旧数据。
  2. 新局域网地址/HTTPS 域名恢复完整备份。
  3. 核对数量、正文、公式、原稿及来源，并再导出新备份。
  4. 完成前保留旧数据。浏览器地址不同则存储隔离，登录不等于同步。
